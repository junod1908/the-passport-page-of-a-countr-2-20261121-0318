The Passport Page of a Country That Isn't There — an open passport spread
from the Republic of Kaldera, a volcanic island nation that does not exist.
The data page shows holder Elara Miren Voss with a machine-readable zone
whose ICAO check digits are computed by the program; the facing page
carries a visitor visa and six arrival/departure stamps whose dates form
one consistent travel chain after the passport's 02 JUN 2023 issue date.
The telling detail: an ash-season travel ban and a volcano levy stamp.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Standard library only. Deterministic: two runs produce identical bytes.
